**Diagnosis result — required output structure**

- `high_risk_patterns` (list) — *High-risk delay pattern combinations for today*
  - `pattern_type` (str) — *Type of pattern combination (mode_weather, mode_distance, weather_vehicle)*
  - `pattern_description` (str) — *Human-readable pattern description (e.g. 'same_day + Stormy')*
  - `total_deliveries` (int) — *Total deliveries matching this pattern*
  - `delayed_count` (int) — *Number of delayed deliveries*
  - `delay_rate_pct` (float) — *Delay rate as percentage*
  - `risk_level` (str) — *Risk level: critical (50%+), high (40-50%), medium (30-40%)*
- `comparison` (list) — *Today vs historical delay rate comparison across all dimensions*
  - `dimension` (str) — *Dimension name (region, weather_condition, delivery_partner, etc.)*
  - `category` (str) — *Category value (East, Stormy, DHL, etc.)*
  - `daily_total` (int) — *Today's total deliveries for this category*
  - `daily_delayed` (int) — *Today's delayed count*
  - `daily_delay_rate_pct` (float) — *Today's delay rate %*
  - `hist_total` (int) — *Historical total deliveries*
  - `hist_delayed` (int) — *Historical delayed count*
  - `hist_delay_rate_pct` (float) — *Historical delay rate %*
  - `rate_change_pct` (float) — *Change in delay rate (daily - hist), negative means improvement*
- `diagnosis_summary` (str) — *Formatted Markdown summary of delay pattern diagnosis, generated by the agent*
